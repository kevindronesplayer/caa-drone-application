# 民航局無人機申請資料填寫系統

網頁工具：畫空域 → 案名與作業概述（AI 擴寫）→ 自動找起飛點 → 輸出 Word／PDF／KML。

**線上使用：<https://kevindronesplayer.github.io/caa-drone-application/>**

## 流程

1. **繪製空域**：多邊形（最多 6 點）或圓形，也可以匯入 KML／KMZ（按鈕或直接拖到地圖上）。選取後拖曳頂點、點虛線圓點新增頂點、點頂點刪除；圓形可拖曳圓心／半徑把手或直接輸入半徑。
   - **每個專案最多 5 個空域**；跨縣市或跨海岸線的空域，每一塊都算一個空域。
   - 「空域N」的 N 就是排列順序：把空域3 改名為空域1 會立刻移到最前面，其他依序重新編號。
   - 地點自動帶入面積最大的縣市鄉鎮（可手動修改）。
   - 每個空域會顯示：與民航局公告限制區重疊的情形、空域內最大地表高度與最低可申請高度（最大地表高度 + 400 ft，無條件進位到百位）、機場 10 公里內的最近跑道頭距離（海里／公里，3 海里以內顯示「受○○機場近離場影響」）。這些僅顯示在畫面上，不會帶入作業概述或 KML。
2. **案名與作業概述**
   - 案名預設：年份＋季節＋各空域縣市＋「紀錄片拍攝 空拍攝影」，例如「2026秋季台北新北台南紀錄片拍攝 空拍攝影」；勾選「400 呎以上」會加上「(高空)」。可自行修改，或按「套用預設格式」還原。
   - 作業概述：預設顯示以下範本，在第一段填入片名、委託單位與拍攝內容，可按「AI 潤飾第一段」；【預計起飛地點】在步驟 3 貼入，每次進入步驟 4 也會自動更新：

     ```
     本案係辦理「片名」紀錄片，受○○委託，（拍攝規劃與內容）。因素材拍攝範圍廣，須執行人群聚集或室外集會遊行上空活動、視距外操作及夜間飛行等操作限制。
     【預計起飛地點】
     空域1（新北市汐止區）：
     　起飛點1：民權公園（25.050102, 121.619866）
     將遵循所有規定並加強安全控管
     ```
3. **預計起飛地點**：每個空域自動產生 2 個起飛點，優先選空域內相距最遠的公園或戶外停車場，不足時用廟宇，再不足才用空域對角線位置。地圖上會直接顯示起飛點名稱（沒有名稱的地點以附近路名命名，例：民權路旁停車場）；可在地圖上點選、拖曳、新增、刪除，「貼到作業概述」會更新【預計起飛地點】段落。
4. **確認與輸出**：所有欄位都能修改。輸出 Word、PDF（第一行「作業概述」，其後為內容，標楷體；PDF 於列印視窗選「另存為 PDF」）與 KML（每個空域一個檔案，檔名「地點_空域N.kml」）。

資料會自動存在瀏覽器；「儲存專案」可下載 .json，之後用「開啟專案」繼續編輯。

## AI 擴寫

需要使用者自己的 Claude API 金鑰（<https://console.anthropic.com/settings/keys>），在步驟 2 輸入一次即可。金鑰只存在使用者自己的瀏覽器，直接傳給 Claude API，不會存進專案檔或上傳到其他地方。

## 資料來源

純靜態網頁（`docs/`），由 GitHub Pages 提供。

| 項目 | 來源 |
|---|---|
| 底圖 | OpenStreetMap、內政部國土測繪中心 |
| 民航局限制區 | 民航局 dronegis UAV_fs 公開圖資，由 GitHub Actions 每天更新至 `docs/data/caa_zones.geojson`（`scripts/update_caa_zones.py`）；僅供參考，以民航局公告為準 |
| 機場跑道頭 | OurAirports，含內移跑道頭修正，每天更新至 `docs/data/tw_runways.json`（`scripts/build_runways.py`） |
| 縣市鄉鎮界線、海岸線 | 內政部國土測繪中心 鄉鎮市區界線（1140318 版），簡化至約 10 公尺：`docs/data/tw_towns.geojson` |
| 地表高度 | AWS Terrain Tiles（約 30 公尺解析度）；僅供參考 |
| 公園／停車場／廟宇 | OpenStreetMap Overpass API |
| 地點搜尋、起飛點附近路名 | OpenStreetMap Nominatim |
| AI 擴寫 | Claude API（Anthropic TypeScript SDK） |
| Word | docx 函式庫 |
